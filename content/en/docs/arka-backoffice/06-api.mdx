## HTTP Routes

Route Handlers under `src/app/api/`. All require an authenticated Supabase session cookie unless noted.

---

### `POST /api/webhooks/tally-return`

Receives Tally form submissions for product returns. Called by Tally, not the browser.

**Auth:** `?secret=<TALLY_WEBHOOK_SECRET>` query param (timing-safe comparison). No session required.

**Request body:**
```json
{
  "data": {
    "submissionId": "string",
    "respondentId": "string",
    "createdAt": "ISO timestamp",
    "fields": [
      { "label": "string", "type": "TEXT|FILE_UPLOAD|MULTIPLE_CHOICE", "value": "..." }
    ]
  }
}
```

**Behavior:**
1. Verifies `?secret` with `timingSafeEqual`
2. Parses field map; resolves MULTIPLE_CHOICE option IDs to labels
3. Detects `has_service_fee` from presence of `FILE_UPLOAD` slip fields
4. If `has_service_fee`: calls EasySlip API to verify slip against `app_settings.service_fee_amount`
5. Checks `submission_id` for idempotency
6. Inserts `product_returns` row
7. Sends LINE notification: `NEW_NO_FEE` | `NEW_SLIP_OK` | `NEW_SLIP_FAIL`

**Response:** `{ "status": "ok" }` or `{ "error": "..." }` with 4xx/5xx.

---

### `GET /api/labels/pdf?ids=uuid1,uuid2,...`

Generates printable PDF with QR-code labels for one or more product variants.

**Auth:** Session + `labels:print` permission.

**Query params:** `ids` — comma-separated variant UUIDs (max 200).

**Response:** `Content-Type: application/pdf` — QR code encodes the SKU string, label shows SKU, product name, size, box number, and variant image.

---

### `GET /api/returns/[id]/label`

Return shipping label PDF for one return record.

**Auth:** Session + `returns:read`.

**Response:** `Content-Type: application/pdf` — customer name, delivery address, return reference.

---

### `GET /api/returns/labels`

Bulk return label PDF (multiple return records in one file).

**Auth:** Session + `returns:read`.

---

### `GET /api/orders/[id]/po`

Purchase order document PDF for a given PO.

**Auth:** Session + `po:read`.

---

### `GET /api/orders/tax-evidence`

Export tax evidence document for customs/accounting.

**Auth:** Session + `po:read`.

---

### `GET /api/audit/export`

Exports audit log entries as CSV or JSON.

**Auth:** Session + `audit:read`.

---

### `GET /api/cron/daily-report`

Vercel cron job. Sends daily summary via LINE. Protected by `Authorization: Bearer <CRON_SECRET>` header.

---

## Server Actions

All Server Actions in `src/app/actions/`. Mutations check permission before any DB write. Reads check permission and return empty/null for unauthorized callers rather than throwing.

### Stock (`actions/stock.ts`)

```ts
getVariantBySku(sku: string): Promise<VariantInfo | null>
// Exact match on v_current_stock. Used by QR scan.

searchVariantsBySku(query: string): Promise<VariantInfo[]>

// Inserts: transaction_type='sale'

recordCorrection(data: CorrectionData): Promise<{ error: string | null }>

```

```ts
type VariantInfo   = { variant_id: string; style_code: string; name_en: string|null; color: string|null; size: string; sku: string; box_no: string|null; current_stock: number|null }
```

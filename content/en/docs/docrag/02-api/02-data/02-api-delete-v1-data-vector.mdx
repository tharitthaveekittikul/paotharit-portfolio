<Callout type="abstract">
Clears all points from the Qdrant collection by dropping and recreating it empty. This is a destructive, irreversible operation — all indexed documents are permanently deleted. Exposed via the Storage Settings panel's "Clear Vector Store" button.
</Callout>

---

## 🔒 Authentication

None.

---

## 🛠️ Technical Specification

### Request

| Property | Value |
| :--- | :--- |
| **Method** | `DELETE` |
| **Path** | `/api/v1/data/vector` |
| **Tags** | `["Data"]` |

### Logic Flow

```mermaid
sequenceDiagram
    participant Client
    participant Router as DELETE /data/vector
    participant VecService as vector_service
    participant Qdrant

    Client->>Router: DELETE /api/v1/data/vector
    Router->>VecService: clear_all()
    VecService->>Qdrant: delete_collection + recreate_collection
    Qdrant-->>VecService: ok
    Router-->>Client: 200 { message: "Vector store cleared" }
```

### 📤 Responses

| Status | Body | Condition |
| :--- | :--- | :--- |
| `200 OK` | `{ message: "Vector store cleared" }` | Collection dropped and recreated |

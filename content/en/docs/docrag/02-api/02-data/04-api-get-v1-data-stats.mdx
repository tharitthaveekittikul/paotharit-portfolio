<Callout type="abstract">
Returns the total number of vector points (chunks) and unique files currently indexed in the Qdrant collection. Used by the Storage Settings panel to display vector store usage.
</Callout>

---

## 🔒 Authentication

None.

---

## 🛠️ Technical Specification

### Request

| Property | Value |
| :--- | :--- |
| **Method** | `GET` |
| **Path** | `/api/v1/data/stats` |
| **Tags** | `["Data"]` |

### 📤 Responses

| Status | Body | Condition |
| :--- | :--- | :--- |
| `200 OK` | `{ total_chunks: int, unique_files: int }` | Always succeeds |

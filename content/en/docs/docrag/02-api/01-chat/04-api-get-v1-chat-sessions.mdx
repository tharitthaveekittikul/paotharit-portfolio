<Callout type="abstract">
Returns all `ChatSession` rows ordered by `created_at` descending (newest first). Called by `AppSidebar` on mount to populate the session list and reconcile the Zustand store cache.
</Callout>

---

## 🔒 Authentication

None.

---

## 🛠️ Technical Specification

### Request

| Property | Value |
| :--- | :--- |
| **Method** | `GET` |
| **Path** | `/api/v1/chat/sessions` |
| **Tags** | `["Chat"]` |

### Logic Flow

```mermaid
sequenceDiagram
    participant Client
    participant Router as GET /chat/sessions
    participant DB as PostgreSQL

    Client->>Router: GET /api/v1/chat/sessions
    Router->>DB: SELECT * FROM chatsession ORDER BY created_at DESC
    DB-->>Router: ChatSession[]
    Router-->>Client: 200 ChatSession[]
```

### 📤 Responses

| Status | Body | Condition |
| :--- | :--- | :--- |
| `200 OK` | `ChatSession[]` (array, may be empty) | Always succeeds |

Each `ChatSession`: `{ id, title, provider, model_name, created_at, updated_at }`.

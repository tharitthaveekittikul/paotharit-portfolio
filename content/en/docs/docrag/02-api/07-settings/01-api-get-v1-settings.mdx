<Callout type="abstract">
Returns all settings from the `appsetting` table as a flat `dict[str, str | null]`. Sensitive keys (API keys) are masked as `"****"` if set. Used by the Settings page to populate all input fields on load.
</Callout>

---

## 🔒 Authentication

None.

---

## 🛠️ Technical Specification

### Request

| Property | Value |
| :--- | :--- |
| **Method** | `GET` |
| **Path** | `/api/v1/settings` |
| **Tags** | `["Settings"]` |

### Logic Flow

```mermaid
sequenceDiagram
    participant Client
    participant Router as GET /settings
    participant Service as settings_service
    participant DB as appsetting table

    Client->>Router: GET /api/v1/settings
    Router->>Service: get_all(db)
    Service->>DB: SELECT * FROM appsetting
    DB-->>Service: { key: value, ... }
    Router->>Router: apply ollama_base_url default if unset
    Router->>Router: mask sensitive keys (value → "****" if set)
    Router-->>Client: 200 { key: "****" | value | null }
```

### 📤 Responses

| Status | Body | Condition |
| :--- | :--- | :--- |
| `200 OK` | `dict[str, str \| null]` — all settings, sensitive keys masked | Always succeeds |

**Sensitive keys** (masked as `"****"` when set): `openai_api_key`, `anthropic_api_key`, `gemini_api_key`, `openrouter_api_key`, `moonshot_api_key`, `minimax_api_key`, `zai_api_key`.

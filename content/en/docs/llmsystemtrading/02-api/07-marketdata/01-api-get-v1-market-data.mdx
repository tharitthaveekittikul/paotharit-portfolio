<Callout type="abstract">
Fetch live OHLCV candle data from MT5 for a given symbol and timeframe — used by the Chart page and LLM analysis pipeline to get current price data.
</Callout>

## 🔒 Authentication

| Property | Value |
| :--- | :--- |
| **Mechanism** | None |
| **Required** | No |

## 🛠️ Technical Specification

### Request

| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `symbol` | Path | `string` | Yes | Trading pair (e.g., `EURUSD`, `XAUUSD`) |
| `timeframe` | Path | `string` | Yes | Candle timeframe: `M1`, `M5`, `M15`, `M30`, `H1`, `H4`, `D1` |
| `count` | Query | `integer` | No | Number of candles (default: 100) |
| `account_id` | Query | `integer` | No | Account to use for MT5 connection |

### Logic Flow

```mermaid
sequenceDiagram
    autonumber
    participant Client as Frontend / AI Pipeline
    participant API as FastAPI Router
    participant MT5 as MT5Bridge
    participant QDB as QuestDB (cache)

    Client->>API: GET /api/v1/market-data/EURUSD/H1?count=200
    API->>QDB: Check cache for recent candles
    alt Cache hit (< 1 candle period old)
        QDB-->>API: Cached OHLCV
    else Cache miss
        API->>MT5: copy_rates_from_pos(symbol, tf, 0, count)
        MT5-->>API: OHLCV rows
        API->>QDB: Store latest candles
    end
    API-->>Client: 200 OK OHLCV[]
```

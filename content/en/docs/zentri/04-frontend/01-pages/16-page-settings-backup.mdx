## Page Lifecycle
```mermaid
sequenceDiagram
    autonumber
    participant U as User
    participant P as BackupPage
    participant API as Backend

    U->>P: Click "Download Backup"
    P->>API: "exportSystem()" — GET /api/v1/system/export
    API-->>P: JSON file blob
    P->>U: Browser downloads backup JSON

    U->>P: Click "Refresh Names"
    P->>API: "refreshAssetNames()" — POST /api/v1/portfolio/refresh-names
    API-->>P: "{ updated: N }"
    P->>U: toast.success with count

    U->>P: Click "Restore from Backup", select file
    P->>P: setPendingFile(file), setConfirmOpen(true)
    U->>P: Click "Yes, restore" in dialog
    P->>API: "importSystem(file)" — POST /api/v1/system/import multipart
    API-->>P: 200 OK
    P->>P: setConfirmOpen(false), setImporting(false)
    P->>U: toast.success "Restore complete"
```

## Validation & Conditions

### Form Validation
- File input accepts only `.json` files (`accept=".json"`).
- Restore requires a two-step confirmation dialog — file selection alone does not trigger the import.
- `handleConfirmImport()` calls `importSystem(pendingFile)` only after user confirms in the dialog.

### Render Conditions
| Condition | Rendered |
| :--- | :--- |
| `exporting === true` | Export button disabled + "Exporting..." text |
| `importing === true` | Restore button disabled + "Restoring..." text |
| `refreshing === true` | Refresh button disabled + "Refreshing..." text |
| `confirmOpen === true` | Confirmation dialog visible |
| Always | Security warning banner (backup files contain API keys in plaintext) |

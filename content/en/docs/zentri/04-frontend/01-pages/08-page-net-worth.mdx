## Page Lifecycle
```mermaid
sequenceDiagram
    autonumber
    participant U as User
    participant P as NetWorthPage
    participant C as NetWorthChart
    participant API as Backend

    P->>P: read isPrivate from usePrivacyStore
    P->>C: render NetWorthChart (privacyMode)
    C->>API: fetch net worth history data
    API-->>C: time-series data
    C->>C: render chart (mask values if privacyMode)
    U->>P: toggle privacy mode (elsewhere in app)
    P->>P: isPrivate updates from Zustand
    P->>C: re-render with updated privacyMode
```

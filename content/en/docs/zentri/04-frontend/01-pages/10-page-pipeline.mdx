### Local State — `useState`
| Variable | Type | Purpose |
| :--- | :--- | :--- |

## Page Lifecycle
```mermaid
sequenceDiagram
    autonumber
    participant U as User
    participant P as PipelinePage
    participant API as Backend
    participant SSE as "SSE /api/v1/pipeline/stream"

    P->>API: fetchJobs(50) via React Query
    API-->>P: last 50 jobs
    P->>P: setJobs (seed local state)
    P->>SSE: new EventSource (JWT as ?token= query param)
    SSE-->>P: onmessage → updated PipelineJob[] (JSON)
    P->>P: setJobs (replace with latest from SSE)
    U->>P: click trigger button (in TriggerButtons)
    P->>API: trigger job request
    API-->>SSE: job status update pushed
    SSE-->>P: onmessage → new jobs list
    P->>P: setJobs → JobsTable re-renders
    P->>P: component unmount → es.close()
```

## Validation & Conditions

### Form Validation (if any)
| Rule | Where enforced |
| :--- | :--- |
| None | Page is read-only except for trigger actions in `TriggerButtons` |

### Render Conditions
| Condition | Rendered |
| :--- | :--- |
| `isLoading` is true | 8-row Skeleton placeholder |
| `isLoading` is false | Full page with `TriggerButtons` + `JobsTable` |
| `jobs.length === 0` | `JobsTable` renders empty state (handled internally) |

## Overview
<Callout type="abstract">
Returns the main Market Overview dashboard data: total portfolio value, daily change, top movers, and any active AI BUY/SELL alerts. This is the first call made when the user opens Zentri.
</Callout>

## 🔒 Authentication
- **Mechanism:** Bearer JWT

## 🛠️ Technical Specification

### Request
| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | Header | String | Yes | `Bearer {access_token}` |

**200 OK**

  "total_pnl_pct": 25.0,

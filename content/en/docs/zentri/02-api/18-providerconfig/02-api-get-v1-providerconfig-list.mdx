## Overview
Returns all LLM provider configurations belonging to the authenticated user. Encrypted API keys are never returned — the `ProviderConfigOut` schema exposes only safe fields.

## 🔒 Authentication
| Field | Value |
| :--- | :--- |
| Required | Yes |
| Mechanism | JWT Bearer token via `get_current_user` |

## 🛠️ Technical Specification

### Request
| Field | Value |
| :--- | :--- |
| Method | `GET` |
| Path | `/api/v1/provider-configs` |
| Path Params | — |
| Query Params | — |
| Request Body | — |

### Logic Flow
```mermaid
sequenceDiagram
    autonumber
    participant C as Frontend
    participant A as "provider_config.py"
    participant DB as TimescaleDB

    C->>A: GET /api/v1/provider-configs
    Note over A: Validate JWT
    A->>DB: SELECT FROM provider_configs WHERE user_id = current_user.id
    DB-->>A: list of ProviderConfig rows
    A-->>C: 200 OK list[ProviderConfigOut]
```

### 📤 Responses
| Status | Description | Body |
| :--- | :--- | :--- |
| 200 | Success | `list[ProviderConfigOut]` |
| 401 | Missing or invalid JWT | `{"detail": "..."}` |

## Overview
<Callout type="abstract">
Returns the most recent BUY/SELL/HOLD analysis result for an asset, including the verdict, reasoning, target price, and LLM cost. Displayed on the asset detail page.
</Callout>

## 🔒 Authentication
- **Mechanism:** Bearer JWT

## 🛠️ Technical Specification

### Request
| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | Header | String | Yes | `Bearer {access_token}` |
| `symbol` | Path | String | Yes | Asset symbol |

### 📤 Responses

**200 OK**
```json
{
  "id": "uuid",
  "symbol": "AAPL",
  "verdict": "hold",
  "target_price": 195.00,
  "reasoning": "Apple's Q4 earnings showed strong services growth at 18% YoY. Current price at $180 is near fair value based on DCF at a 9% discount rate. No catalyst for immediate upside. Recommend holding and reassessing after next earnings.",
  "model_used": "claude-3-5-sonnet-20241022",
  "tokens_in": 4200,
  "tokens_out": 380,
  "cost_usd": 0.014,
  "created_at": "2026-04-22T10:30:00Z"
}
```

**404 Not Found** — No analysis exists for this symbol yet

**401 Unauthorized**

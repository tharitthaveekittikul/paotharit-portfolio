## Overview
<Callout type="abstract">
Returns the full LLM conversation log for a specific analysis run. Shown in the AI Usage page as an expandable conversation history. Includes system prompt, context chunks, and model response.
</Callout>

## 🔒 Authentication
- **Mechanism:** Bearer JWT

## 🛠️ Technical Specification

### Request
| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | Header | String | Yes | `Bearer {access_token}` |
| `id` | Path | UUID | Yes | Analysis ID |

### 📤 Responses

**200 OK**
```json
{
  "analysis_id": "uuid",
  "symbol": "AAPL",
  "messages": [
    {
      "role": "user",
      "content": "Analyze Apple Inc. (AAPL)...",
      "tokens": 4200
    },
    {
      "role": "assistant",
      "content": "Based on the Q4 2025 10-K and current price of $180...",
      "tokens": 380
    }
  ],
  "total_cost_usd": 0.014,
  "created_at": "2026-04-22T10:30:00Z"
}
```

**404 Not Found** — Analysis ID not found

**401 Unauthorized**

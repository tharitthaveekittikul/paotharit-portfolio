## Overview
<Callout type="abstract">
Issues a new access token using a valid refresh token. Prevents users from being logged out when the short-lived access token expires.
</Callout>

## 🔒 Authentication
- **Mechanism:** Refresh token (from httpOnly cookie or request body)

## 🛠️ Technical Specification

### Request
| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `refresh_token` | Body | String | Yes | Long-lived refresh token |

### 📤 Responses

**200 OK**
```json
{
  "access_token": "eyJhbGci..."
}
```

**401 Unauthorized** — Refresh token invalid, expired, or blacklisted

## Overview
Deletes the platform color configuration for the given platform name belonging to the authenticated user. Returns 404 if the named platform config does not exist for this user.

## 🔒 Authentication
| Field | Value |
| :--- | :--- |
| Required | Yes |
| Mechanism | JWT Bearer token via `get_current_user` |

## 🛠️ Technical Specification

### Request
| Field | Value |
| :--- | :--- |
| Method | `DELETE` |
| Path | `/api/v1/platforms/{name}` |
| Request Body | — |

**Path Parameters:**
| Param | Type | Description |
| :--- | :--- | :--- |
| `name` | `string` | Platform name to delete |

### Logic Flow
```mermaid
sequenceDiagram
    autonumber
    participant C as Frontend
    participant A as "platforms.py"
    participant DB as TimescaleDB

    C->>A: DELETE /api/v1/platforms/{name}
    Note over A: Validate JWT
    A->>DB: DELETE FROM platform_configs WHERE user_id = current_user.id AND name = name RETURNING id
    DB-->>A: deleted row id or None
    Note over A: If None raise 404
    A->>DB: COMMIT
    A-->>C: 204 No Content
```

### 📤 Responses
| Status | Description | Body |
| :--- | :--- | :--- |
| 204 | Deleted | — |
| 401 | Missing or invalid JWT | `{"detail": "..."}` |
| 404 | Platform config not found | `{"detail": "Platform config not found"}` |

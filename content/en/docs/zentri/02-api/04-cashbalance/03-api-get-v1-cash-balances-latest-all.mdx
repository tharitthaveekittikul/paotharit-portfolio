## Overview

Returns the most recent balance snapshot for every cash asset belonging to the authenticated user. Used to display current cash account balances on the Portfolio page.

## 🔒 Authentication

| Field | Value |
| :--- | :--- |
| Required | Yes |
| Mechanism | JWT Bearer token via `get_current_user` |

## 🛠️ Technical Specification

### Request

| Field | Value |
| :--- | :--- |
| Method | `GET` |
| Path | `/api/v1/cash-balances/latest` |
| Query params | None |

### Logic Flow

```mermaid
sequenceDiagram
    autonumber
    participant C as Frontend
    participant A as "cash_balance.py"
    participant S as "cash_balance service"
    participant DB as TimescaleDB

    C->>A: GET /api/v1/cash-balances/latest
    Note over A: Validate JWT
    A->>S: "get_all_latest(user_id)"
    S->>DB: "SELECT DISTINCT ON (asset_id) latest snapshot per asset"
    DB-->>S: list of CashBalance rows
    S-->>A: "list[CashBalanceOut]"
    A-->>C: 200 OK
```

### 📤 Responses

**200 OK** — list of latest balance per cash asset (may be empty)

**401 Unauthorized**

## Overview
Resets the system prompt of a Feature LLM Config back to the platform default for its `feature_key`. Sets `is_prompt_customized` to `false`. No request body required.

## 🔒 Authentication
| Field | Value |
| :--- | :--- |
| Required | Yes |
| Mechanism | JWT Bearer token via `get_current_user` |

## 🛠️ Technical Specification

### Request
| Field | Value |
| :--- | :--- |
| Method | `POST` |
| Path | `/api/v1/feature-llm-configs/{config_id}/reset-prompt` |
| Request Body | — (none) |

**Path Parameters:**
| Param | Type | Description |
| :--- | :--- | :--- |
| `config_id` | `uuid` | ID of the FeatureLLMConfig to reset |

### Logic Flow
```mermaid
sequenceDiagram
    autonumber
    participant C as Frontend
    participant A as "feature_llm_config.py"
    participant DB as TimescaleDB

    C->>A: POST /api/v1/feature-llm-configs/{config_id}/reset-prompt
    Note over A: Validate JWT
    A->>DB: SELECT FROM feature_llm_configs WHERE id = config_id AND user_id = current_user.id
    DB-->>A: FeatureLLMConfig row or 404
    Note over A: Set system_prompt = DEFAULT_SYSTEM_PROMPTS[feature_key]
    Note over A: Set is_prompt_customized = false
    A->>DB: COMMIT
    DB-->>A: refreshed row
    A-->>C: 200 OK FeatureLLMConfigOut
```

### 📤 Responses
| Status | Description | Body |
| :--- | :--- | :--- |
| 200 | Reset successful | `FeatureLLMConfigOut` |
| 401 | Missing or invalid JWT | `{"detail": "..."}` |
| 404 | Config not found or not owned | `{"detail": "Feature LLM config not found"}` |

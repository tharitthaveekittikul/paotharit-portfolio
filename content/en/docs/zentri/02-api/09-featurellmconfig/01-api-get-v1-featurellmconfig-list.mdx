## Overview
Returns all Feature LLM Config records belonging to the authenticated user. Each record maps a product feature (e.g. `chat`, `analysis`) to a specific LLM provider config and model, along with its system prompt.

## 🔒 Authentication
| Field | Value |
| :--- | :--- |
| Required | Yes |
| Mechanism | JWT Bearer token via `get_current_user` |

## 🛠️ Technical Specification

### Request
| Field | Value |
| :--- | :--- |
| Method | `GET` |
| Path | `/api/v1/feature-llm-configs` |
| Path Params | — |
| Query Params | — |
| Request Body | — |

### Logic Flow
```mermaid
sequenceDiagram
    autonumber
    participant C as Frontend
    participant A as "feature_llm_config.py"
    participant DB as TimescaleDB

    C->>A: GET /api/v1/feature-llm-configs
    Note over A: Validate JWT
    A->>DB: SELECT FROM feature_llm_configs WHERE user_id = current_user.id
    DB-->>A: list of FeatureLLMConfig rows
    A-->>C: 200 OK list[FeatureLLMConfigOut]
```

### 📤 Responses
| Status | Description | Body |
| :--- | :--- | :--- |
| 200 | Success | `list[FeatureLLMConfigOut]` |
| 401 | Missing or invalid JWT | `{"detail": "..."}` |

```json

```

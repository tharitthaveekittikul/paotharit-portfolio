## Overview

Creates a new chat session for the authenticated user. Returns the created session. Title is optional and defaults to `"New Chat"` if omitted; capped at 60 characters.

---

## 🔒 Authentication

| Field | Value |
| :--- | :--- |
| Required | Yes |
| Mechanism | JWT Bearer token via `get_current_user` |

---

## 🛠️ Technical Specification

### Request

| Field | Value |
| :--- | :--- |
| Method | `POST` |
| Path | `/api/v1/chat/sessions` |
| Content-Type | `application/json` |

### 📦 Request Body

```json
{ "title": "My new session" }
```

| Field | Type | Required | Notes |
| :--- | :--- | :--- | :--- |
| `title` | string | No | Default `"New Chat"`; truncated to 60 chars |

### Logic Flow

```mermaid
sequenceDiagram
    autonumber
    participant C as Frontend
    participant A as "chat.py router"
    participant DB as TimescaleDB

    C->>A: POST /api/v1/chat/sessions {"title": "..."}
    Note over A: Validate JWT; title = (body.title or "New Chat")[:60]
    A->>DB: INSERT INTO chat_sessions (user_id, title)
    DB-->>A: ChatSession row
    A-->>C: 201 Created {SessionResponse}
```

### 📤 Responses

**201 Created**
```json
{
  "id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "title": "My new session",
  "created_at": "2026-05-11T10:00:00Z",
  "updated_at": "2026-05-11T10:00:00Z"
}
```

**401 Unauthorized** — invalid or missing JWT

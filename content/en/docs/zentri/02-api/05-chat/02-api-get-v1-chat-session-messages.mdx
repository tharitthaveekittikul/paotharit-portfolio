## Overview

Returns all messages for a specific chat session, ordered by `created_at` ascending (oldest first). Verifies session ownership before returning messages — returns 404 if session not found or belongs to another user.

---

## 🔒 Authentication

| Field | Value |
| :--- | :--- |
| Required | Yes |
| Mechanism | JWT Bearer token via `get_current_user` |

---

## 🛠️ Technical Specification

### Request

| Field | Value |
| :--- | :--- |
| Method | `GET` |
| Path | `/api/v1/chat/sessions/{session_id}/messages` |
| Request body | None |

| Path param | Type | Notes |
| :--- | :--- | :--- |
| `session_id` | UUID string | Must belong to current user |

### Logic Flow

```mermaid
sequenceDiagram
    autonumber
    participant C as Frontend
    participant A as "chat.py router"
    participant DB as TimescaleDB

    C->>A: GET /api/v1/chat/sessions/{id}/messages
    Note over A: Validate JWT
    A->>DB: SELECT FROM chat_sessions WHERE id=? AND user_id=?
    alt not found
        DB-->>A: None
        A-->>C: 404 Not Found
    else found
        A->>DB: SELECT FROM chat_session_messages WHERE session_id=? ORDER BY created_at ASC
        DB-->>A: list of ChatSessionMessage rows
        A-->>C: 200 OK [MessageResponse]
    end
```

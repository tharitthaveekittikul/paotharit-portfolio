## Overview

Triggers an async refresh of IPO event data from external sources via the arq job queue. Returns 202 Accepted immediately — the actual fetch happens in the background worker.

## 🔒 Authentication

| Field | Value |
| :--- | :--- |
| Required | Yes |
| Mechanism | JWT Bearer token via `get_current_user` |

## 🛠️ Technical Specification

### Request

| Field | Value |
| :--- | :--- |
| Method | `POST` |
| Path | `/api/v1/ipos/refresh` |
| Request body | None |

### Logic Flow

```mermaid
sequenceDiagram
    autonumber
    participant C as Frontend
    participant A as "ipos.py"
    participant Q as "arq Redis queue"
    participant W as Worker

    C->>A: POST /api/v1/ipos/refresh
    Note over A: Validate JWT
    A->>Q: "enqueue job: fetch_ipo_events"
    Q-->>A: job queued
    A-->>C: 202 Accepted
    Note over W: Worker picks up job async
    W->>W: fetch + upsert ipo_events
```

### 📤 Responses

**202 Accepted** — job enqueued; refresh happens asynchronously

**401 Unauthorized**

## Overview
<Callout type="abstract">
Returns all of the user's holdings enriched with current market price, P&L (unrealized), and total allocation percentage. This is the primary data source for the Portfolio page and Market Overview dashboard.
</Callout>

## 🔒 Authentication
- **Mechanism:** Bearer JWT

## 🛠️ Technical Specification

### Request
| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | Header | String | Yes | `Bearer {access_token}` |

### Mermaid Logic

```mermaid
sequenceDiagram
    autonumber
    participant UI as Frontend
    participant API as FastAPI
    participant DB as PostgreSQL
    participant Cache as Redis

    UI->>API: GET /api/v1/portfolio
    API->>Cache: Check portfolio cache (5min TTL)
    alt Cache hit
        Cache-->>API: Cached portfolio data
    else Cache miss
        API->>DB: Query holdings + latest prices
        API->>API: Calculate P&L + allocation %
        API->>Cache: Store result
    end
    API-->>UI: 200 OK { holdings[], summary }
```

## Overview
<Callout type="abstract">
Returns aggregated portfolio summary: total value, P&L, allocation breakdown by asset type. Used by the Market Overview allocation donut chart.
</Callout>

## 🔒 Authentication
- **Mechanism:** Bearer JWT

## 🛠️ Technical Specification

### Request
| Parameter | Location | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `Authorization` | Header | String | Yes | `Bearer {access_token}` |

### 📤 Responses

**200 OK**
```json
{
  "total_value": 125000.00,
  "total_cost": 100000.00,
  "total_pnl": 25000.00,
  "total_pnl_pct": 25.0,
  "allocation": {
    "us_stock": { "value": 90000.00, "pct": 72.0 },
    "crypto":   { "value": 20000.00, "pct": 16.0 },
    "th_fund":  { "value": 10000.00, "pct": 8.0 },
    "gold":     { "value": 5000.00,  "pct": 4.0 }
  },
  "currency": "USD"
}
```

**401 Unauthorized**

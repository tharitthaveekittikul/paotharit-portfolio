# 404 Page Design Spec

**Date:** 2026-05-15  
**Scope:** Custom 404 not-found pages for the paotharit portfolio (Next.js App Router + next-intl)

---

## Overview

Two `not-found.tsx` files covering different error surfaces:

| File | Fires when | Layout shell | i18n |
|------|-----------|--------------|------|
| `src/app/[locale]/not-found.tsx` | A page inside `[locale]/` calls `notFound()` | Full (Header + Footer via locale layout) | EN + TH via `getLocale()` |
| `src/app/not-found.tsx` | URL matches no route at all (e.g. `/nonexistent`) | None — bare HTML only | Hardcoded English |

---

## Tone

Warm and friendly. One short human sentence — a gentle acknowledgement that something went wrong, not a clinical error message.

---

## Visual Layout

Both pages share the same visual structure:

1. **"404" accent** — large display text (`text-8xl sm:text-9xl`), color `{colors.muted}`, rendered as `aria-hidden` decoration (not a heading).
2. **Heading** — warm, human. `{typography.heading}` size and weight, `{colors.ink}`.
3. **Body copy** — one sentence. `{typography.body-md}`, `{colors.body}`.
4. **"Go back" button** — `button-ghost` style, calls `router.back()`. Implemented as a small `"use client"` component.

Content block is horizontally centered using `max-w-3xl px-6 mx-auto`. Vertically, the locale page centers within the `<main>` area using `min-h-[60vh] flex flex-col justify-center`; the root fallback uses `min-h-screen flex flex-col items-center justify-center`.

## Copy

### Locale-aware page (`[locale]/not-found.tsx`)

| Key | EN | TH |
|-----|----|----|
| `notFound.heading` | `Lost in the void` | `หลงทางแล้ว` |
| `notFound.body` | `This page doesn't exist — but the rest of the site does.` | `ไม่พบหน้านี้ แต่ยังมีหน้าอื่นรออยู่นะ` |
| `notFound.back` | `Go back` | `กลับไป` |

### Root fallback (`app/not-found.tsx`)

Hardcoded English — no i18n provider available at this level:
- Heading: `Lost in the void`
- Body: `This page doesn't exist — but the rest of the site does.`
- Button: `Go back`

---

## Components

### `BackButton` (client component)

A minimal `"use client"` component used by both pages. Renders a ghost-style button that calls `router.back()` on click.

- File: `src/components/shared/BackButton.tsx`
- Props: `{ label: string }`
- Uses `useRouter` from `next/navigation`
- Styled as `button-ghost` per DESIGN.md: transparent background, `{colors.muted}` text, `{typography.button}`, `py-2 px-3`, `rounded-lg`, hover shifts text to `{colors.ink}`

### `src/app/[locale]/not-found.tsx`

Server component. Uses `getLocale()` from `next-intl/server` to resolve locale, then `getTranslations('notFound')` for copy. Renders the shared visual layout with translated strings and `<BackButton>`.

### `src/app/not-found.tsx`

Self-contained server component. No providers. Renders the same visual layout with hardcoded English copy and `<BackButton>`. Uses inline Tailwind classes that mirror the design tokens (zinc palette, no shadows).

## What's Not In Scope

- Root `not-found.tsx` does not get Header/Footer — acceptable, this surface is very rare.
- No illustration or animation — large typographic 404 is the only visual element.
- No "suggested links" (projects, blog) — single CTA only ("go back").
